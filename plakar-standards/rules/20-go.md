# Go

gofmt runs after every write. These are the rules a formatter cannot enforce.

## Errors

- Wrap with context and `%w`: `fmt.Errorf("open snapshot %s: %w", id, err)`.
  Lowercase, no trailing punctuation, no "failed to".
- Handle an error or return it, never both. Logging and returning reports one
  failure twice and hands the caller a decision it cannot make.
- `errors.Is` / `errors.As`, never string matching.
- Sentinels are `var ErrFoo = errors.New("foo")` at package scope.

## Control flow

- No `panic` outside `main` and `init`. A backup tool that panics on malformed
  input has lost the user's run.
- Return early. Do not nest the happy path inside an `if`.
- Every goroutine has an owner that knows when it stops. Without a `context`, a
  `WaitGroup` or a channel, it is a leak.
- Honour `context.Context`: check `ctx.Err()` in long loops, pass it down rather
  than storing it in a struct.

## Resources

- `defer` the close on the line after the open. Check the error from `Close` on
  anything that writes.
- No unbounded reads of input you did not produce. `io.LimitReader` or a
  documented cap.

## Types and APIs

- Accept interfaces, return concrete types.
- Interfaces live at the consumer, not beside the implementation.
- Make the zero value usable where that is cheap.
- Exported identifiers have doc comments starting with the identifier name.

## Test mechanics

- Table-driven, named subtests via `t.Run`.
- `t.TempDir()` and `t.Cleanup`, never a hand-rolled path or a global.
- No `time.Sleep` to synchronise. Channels, `sync`, or a fake clock.
- Tests pass under `-race`.
